#The SHM Philosophy

Storage Health Monitor exists for one reason:

To tell the administrator when storage health has changed.

Nothing more.
Nothing less.

#Principles
Silence is good.
Report changes, not statistics.
Every finding must be actionable.
Never guess.
Reliability over features.
Simple is maintainable.

#What SHM is
A storage health engine.
A change detector.
An attention filter.
What SHM is not
A SMART viewer.
A dashboard.
A graphing tool.
An inventory database.
A replacement for vendor utilities.

Vendor tools tell you everything.

SHM tells you what matters.
